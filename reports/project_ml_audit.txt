4. MODEL TRAINING STATUS & VALIDITY OF EXISTING best_model.pkl:
--------------------------------------------------------------------------------
   - model/best_model.pkl is NOT a regressor. It is a RandomForestClassifier with 3 classes.
   - Feature mismatch: fitted on 9 columns: [CGPA, hackathons, research_papers, projects, internships, certificate_count, certificate_score, academic_score, final_skill_index].
   - Runtime Failure: utils.py passes 4 features [academic_score, certificate_score, certificate_count, hackathons]. This raises ValueError during prediction!
   - The exception is swallowed by a try/except block in utils.py, which returns 0.0 for every student!
   - Therefore, the existing best_model.pkl is completely INVALID and BROKEN for the current dataset and inference code.
   - model/skill_index_model_xgb.pkl is a trained XGBRegressor on 12 scaled features, but it was orphaned and not connected to inference.

5. DATA LEAKAGE AUDIT:
--------------------------------------------------------------------------------
   - SUSPICIOUS TARGET LEAKAGE 1: In model/best_model.pkl, final_skill_index was passed as an input feature to predict skill level!
   - SUSPICIOUS TARGET LEAKAGE 2: In v2_improvements/data/synthetic_students.csv, final_skill_index has a 0.9765 correlation with skill_index. It must NEVER be used as an input feature.
   - SUSPICIOUS TARGET LEAKAGE 3: skill_level and scheme_eligible are downstream derived targets from skill_index and must NOT be used as input features for SIS regression.
